# Parse Platform

> Parse is an open-source Backend-as-a-Service. Originally the mobile BaaS company
> acquired by Facebook in 2013 and shut down in 2017, Parse now lives on as the
> community-maintained Parse Platform: a self-hostable Parse Server (Node.js/Express)
> plus first-party SDKs for JavaScript, Apple, Android, Flutter/Dart, PHP, .NET, Swift
> and Arduino, exposing an object store, user auth, files, queries, roles, Cloud Code,
> LiveQuery real-time, push notifications, and a documented REST API.

## APIs
- [Parse REST API Guide](https://docs.parseplatform.org/rest/guide/): Object CRUD, queries, users, sessions, roles, files, analytics, push over HTTP+JSON.
- [Parse Server Guide](https://docs.parseplatform.org/parse-server/guide/): Deploying and configuring Parse Server.
